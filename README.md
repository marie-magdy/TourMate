# 🧭 TourMate — AI-Powered Egyptian Tourism App

TourMate is a full-stack mobile tourism application designed to help travelers explore Egypt intelligently. It combines a React Native (Expo) frontend with a Node.js backend, a Python-based AI recommendation engine, and a computer vision service — all working together to deliver personalized itineraries, landmark recognition, and an AI travel assistant.

## ✨ Features

### 🗺️ Smart Itinerary Planner
- Multi-day trip planning with city, budget (EGP), date range, and daily hours
- AI-driven attraction selection using a 2D knapsack algorithm (time × budget)
- Adaptive per-day budget splitting based on selected spots and city-level pricing
- Liked spots are guaranteed to appear in the itinerary; remaining time is filled by recommendation score
- Geo-clustering keeps each day's stops geographically tight to minimize travel

### 🔍 Attraction Discovery
- Browse popular attractions across Egyptian cities
- Filter by city and category (historical, nature, food, beach, shopping, museum, etc.)
- Full-text search across attraction name, city, description, and categories
- Nearest attractions to user's current city
- Detailed attraction pages with images, rating, price, opening hours, and map pin

### 🤖 TourMate AI Chat Assistant
- Powered by **LLaMA 3.3 70B** via the Groq API
- Specialized Egyptian tourism system prompt covering 20+ landmark types
- Answers questions about attractions, local food, budget advice, packing tips, and safety
- Voice input via Whisper transcription (speech-to-text)
- Voice output via Groq Orpheus TTS (text-to-speech, WAV, multi-chunk for long responses)

### 🎙️ Audio Guide
- AI-generated narration for any attraction in English or Arabic
- Script is generated by LLaMA 3.3 via Groq, then converted to audio by the Orpheus TTS model
- Long scripts are split into chunks ≤ 190 characters and combined into a single WAV stream
- Available directly from the attraction detail screen

### 📸 Landmark Recognition (Computer Vision)
- Take or upload a photo to identify Egyptian landmarks and museum artifacts
- Two TensorFlow Lite models:
  - **Outdoor landmarks** — recognizes 11 major outdoor sites (Pyramids, Sphinx, Citadel of Qaitbay, Bibliotheca Alexandrina, etc.)
  - **Museum artifacts** — recognizes Egyptian museum artifacts
- Confidence threshold of 60% before a result is returned
- On recognition, the full attraction detail is fetched from the database and displayed

### ⭐ Favorites & Saved Plans
- Save any attraction to a personal favorites list
- Save completed itineraries for later viewing
- Delete saved plans individually

### 🏆 Rewards & Points System
- Users earn points for engagement actions
- Admins can manually award bonus points
- Points can be redeemed for rewards listed in the rewards catalog
- Full points history per user

### 🔐 Authentication
- Email/password registration and login with bcrypt hashing
- Google OAuth sign-in
- JWT-based sessions (7-day expiry)
- Change password, edit profile, and delete account
- Role-based access: `user` and `admin`

### 👑 Admin Dashboard
- View platform stats: total users, attractions, favorites, points distributed
- Manage users: view, delete, change roles, manually award points
- Feature flag: enable/disable voice chat per user
- Manage attractions: add, edit, delete with image upload and category assignment
- Top attractions leaderboard by favorites count

### 🗺️ Interactive Map
- Map view of all attractions with city-filtered pins (React Native Maps)
- Web-compatible alternative map view (`map.web.tsx`)
- Tappable pins open an attraction bottom sheet

### 🌍 Localization
- English, Arabic, French, and German translations
- Full i18n string coverage for all screens
- Language preference saved per user in settings

### 🎨 Onboarding & Splash
- Onboarding screen with illustrated slides (native and web variants)
- Animated splash screen

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18+ and npm
- **Python** 3.10+
- **PostgreSQL** database (local or hosted, e.g. Supabase, Neon)
- **Expo CLI** (`npm install -g expo-cli`)
- **Groq API Key** (free at [console.groq.com](https://console.groq.com))
- A physical device or emulator for React Native

---

### Environment Variables

#### `backend/.env`
```env
PORT=3000
DATABASE_URL=postgresql://user:password@host:5432/dbname
JWT_SECRET=your_jwt_secret_here
GROQ_API_KEY=your_groq_api_key_here
BACKEND_IP=192.168.x.x        # Local IP for image URL generation
API_KEY=your_cv_service_key   # Shared secret for CV service
```

#### `recommendation_service/.env`
```env
DATABASE_URL=postgresql://user:password@host:5432/dbname
```

#### `cv_service/.env`
```env
API_KEY=your_cv_service_key   # Must match backend API_KEY
```

#### `frontend/.env`
```env
EXPO_PUBLIC_API_URL=http://192.168.x.x:3000   # Your backend IP and port
```

---

### Running the Backend

```bash
cd backend
npm install
npm run dev       # Development with hot reload (node --watch)
# or
npm start         # Production
```

The server starts on **port 3000** and connects to PostgreSQL on startup.

---

### Running the Recommendation Service

```bash
cd recommendation_service
pip install -r requirements.txt
python app.py
```

Runs on **port 5002**. Loads attraction data from PostgreSQL on startup and builds the feature matrix for cosine-similarity scoring.

---

### Running the CV Service

```bash
cd cv_service
pip install -r requirements.txt
py -3.9 app.py
```

Runs on **port 5001**. Loads both TFLite models into memory on startup. Requires an `API_KEY` header on all recognition requests.

---

### Running the Frontend

```bash
cd frontend
npm install
npx expo start
```

Scan the QR code with Expo Go, or run on a connected emulator. For web:

```bash
npx expo start --web
```

## 🤖 Services Overview

### Recommendation Engine (`recommendation_service/`)

The recommendation service is a Python Flask API exposing three endpoints. The core logic (`reccomender_v2.py`) implements:

- **Feature matrix**: each attraction is encoded as a 30-dimensional vector across all categories (`ancient`, `beach`, `museum`, `historical`, etc.)
- **Cosine similarity scoring**: user interest vector vs. attraction category vector (weight 60%)
- **Popularity and rating bonuses** (weight 20% and 10%)
- **Price score** relative to available budget (weight 10%)
- **Liked spot guarantee**: user-selected spots are always included; remaining slots are filled by recommendation score
- **Geo-clustering**: attractions are grouped by location per day using city-tuned radius limits to prevent zigzag days
- **2D knapsack (DP)**: discretized time × budget grid to find the optimal set of fill attractions
- **Taxi cost estimation**: city-specific taxi rates (base fare + per-km rates) integrated into day cost budgets
- **Adaptive budget splitting**: per-day budget fractions are computed from the price distribution of liked spots across days

Supports 10 Egyptian cities: Cairo, Alexandria, Luxor, Aswan, Hurghada, Sharm El Sheikh, Dahab, Marsa Matrouh, Siwa, and El Gouna.

### Computer Vision Service (`cv_service/`)

A Python Flask API that runs two TensorFlow Lite image classification models:

- **Outdoor Landmarks model** (`outdoor_landmarks.tflite`): classifies 11 outdoor sites including the Great Pyramids, Sphinx, Bibliotheca Alexandrina, Montaza Palace, Citadel of Qaitbay, Stanley Bridge, and more.
- **Museum Artifacts model** (`museum_artifacts.tflite`): classifies Egyptian museum artifacts.

Images are resized to 224×224 and normalized before inference. Results with confidence below 60% are rejected. The service is protected by a shared API key passed as an `x-api-key` header.

## 🗄️ Database Schema

Key tables in PostgreSQL:

| Table | Description |
|---|---|
| `users` | User accounts (id, username, email, password, role, avatar_url) |
| `cities` | Egyptian cities (city_id, name) |
| `attractions` | Attractions (id, attraction_id, name, city_id, description, rating, price_from, opening_hours, is_popular, latitude, longitude, model_label) |
| `attraction_images` | Multiple images per attraction with primary flag |
| `attraction_categories` | Join table linking attractions to categories |
| `categories` | Category definitions |
| `favorites` | User-attraction favorites |
| `hotels` | Hotel listings per city |
| `user_points` | Points balance and total earned per user |
| `points_history` | Audit log of all point transactions |
| `rewards` | Reward catalog items with points_required |
| `saved_plans` | Saved itinerary plans (JSONB for itinerary, interests, spot_ids) |
| `user_feature_flags` | Per-user feature toggles (e.g., voice_chat_enabled) |

> **Note:** The recommendation engine uses `attraction_id` (e.g. `ATT001`) from the attractions table, while the main browse flow uses the integer serial `id`. Both are supported in the `/api/attractions/:id` route.

## 👑 Admin Panel

Access the admin panel by logging in with an account that has `role = 'admin'`. Admin screens are under the `(admin)` route group and include:

- **Dashboard** — Platform-wide stats and top attractions by favorites
- **Manage Attractions** — Full CRUD with image upload, category selection, and city assignment
- **Manage Users** — View all users, change roles, award bonus points, enable/disable voice chat access

## 🌍 Localization

TourMate supports four languages via the `constants/i18n.ts` translation file:

| Code | Language |
|---|---|
| `en` | English (default) |
| `ar` | Arabic |
| `fr` | French |
| `de` | German |

Language is selected from the Settings screen and applied app-wide via the `AppContext`. The AI audio guide also supports English and Arabic narration via the Groq TTS system.
